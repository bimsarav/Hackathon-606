# ADR-0002: Self-issued RS256 JWT with JWKS

- **Status:** Accepted (2026-11-19) · pending PO review (SSO)
- **Context:** No identity provider was supplied (BQ-9). Services must authenticate requests without calling each other.
- **Decision:** directory-service issues 60-minute RS256 tokens (claims sub, cid, roles, teams, name, email) and publishes JWKS. Every service is a resource server. The design is OIDC-compatible: an external IdP can replace the issuer later.
- **Consequences:** Stateless and scalable. Revocation before expiry happens only through deactivation and short TTLs.
