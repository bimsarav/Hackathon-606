## C. Strengths
1. Both UC5 scenarios work end to end on the provided VM with the provided data ([V] in browser).
2. Passenger rights are structurally protected: tiers (mandated care, urgency) before any commercial weight; non-revenue last; the UI says so beside the weight sliders.
3. Grounded AI: engine computes, the model words; template fallback; source label ("Text written by claude-opus-5-5" / "Template") on every text.
4. Agent is transparent: 7 visible tool steps, reasons, risks and "checks before approving"; it recommends only and hands over to the scenario for human approval.
5. Human-in-the-loop with audit (`decided_by` = user and role) and a clear "nothing changes in airline systems" message.
6. Role separation enforced server-side (403) and client-side, verified by the Judge.
7. Strong engineering evidence trail: ADRs, model cards, backtest, cascade check, test report, rollback points.
