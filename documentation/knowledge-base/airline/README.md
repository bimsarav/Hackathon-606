# Airline Domain Knowledge Base

Workspace knowledge built under MASTER_PROMPT §15 (rules: `instructions/DOMAIN_RESEARCH_RULES.md`). Reused across products; it is not a product deliverable.

## Files
- `SOURCES.md` – source registry (`S-NNN`, tier, publisher, date, URL, accessed). Every note cites these IDs.
- `GLOSSARY.md` – terms and abbreviations, each with a source.
- `topics/` – one folder per researched business problem.

## Claim labels
`[STD]` standard/regulation · `[PRACTICE]` common industry practice · `[SPECIFIC]` one airline/vendor · `[ACADEMIC]` research/theory · `[AI-OPP]` potential AI improvement · `[VALIDATE]` assumption to confirm with the airline
